# SJA Robotics

Empowering Everyday Life Through Automation.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Tech Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS v4**

## Structure

- `src/app/` - Pages and layouts
- `src/components/` - Reusable UI components (Navbar, Hero, About, Products, Vision, Footer)
